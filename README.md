# Kavindu Jayawardhana — GitHub Pages homepage

Personal portfolio site at <https://j-kavindu.github.io/>. This repository is the GitHub Pages user site; the other projects remain in their own repositories and retain their existing URLs.

The site is a single static `index.html` with no build step or external JavaScript dependencies. Project descriptions link to the corresponding repositories. The CSE Portfolio Tracker preview uses an image hosted by that project's repository and shows sample figures.
