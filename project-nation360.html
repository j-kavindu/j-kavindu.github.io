NATION 360

An economic journey from a first wage to presidential decisions.

Release candidateReactTypeScriptPhaser 3HTML Audio
Play game ↗Deployment repository

The problem

What the project addresses

Economic ideas are easier to explore when choices have visible costs, constraints and consequences.

The approach

A practical workflow

A two-level simulation connecting work, farming, trade and enterprise with a later presidential economy. Players progress through milestones before Level II unlocks.

  • Manual wage shifts, farming and business progression
  • Budget, debt, foreign-exchange and Balance of Payments systems
  • Browser saves, task animation and original supplied theme music

Subject & technology

What it demonstrates

Economic modelling · interactive learning · game interfaces.

Project stack: React, TypeScript, Phaser 3, HTML Audio.

Evidence & scope

Verification and limitations

The separate release project passed 121 automated tests. A live desktop smoke check confirmed menu rendering, theme playback, job-panel dismissal and the first $10 mining wage. These results do not establish complete gameplay acceptance.

Version 1.0.1 release candidate. The public repository contains deployment assets, not the editable TypeScript project. Full mobile and physical-device acceptance remain pending.
